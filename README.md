How can an AI-based quoting agent learn to adapt as prices, liquidity and inventory change?

<img width="1511" height="814" alt="image" src="https://github.com/user-attachments/assets/32fb1c16-baf4-4585-ad23-21ec6efe28bd" />

I built a Python and Flask market-making simulator to explore that question. It combines dynamic Avellaneda–Stoikov quotes with a Q-learning agent that adjusts reservation price, spread and order size based on simulated market conditions.

𝗜𝗻𝘀𝗶𝗱𝗲 𝘁𝗵𝗲 𝘀𝗶𝗺𝘂𝗹𝗮𝘁𝗼𝗿:

• A changing order book and zoomable price history  
• Manual long and short orders that affect the simulated market  
• Live tracking of fills, inventory, P&L and training metrics  
• An agent that learns from changes in account equity while accounting for inventory risk

For exchanges, liquidity providers, market-making desks and quant teams, this is a sandbox for studying **adaptive quoting and execution** before deploying real capital.

It is a simulation—not a live trading system or evidence of profitable performance.
